## 本地运行

在此目录执行 `node preview.cjs`，访问 http://127.0.0.1:4173/ 。Windows 下也可双击 `启动本地预览.cmd`。音频通过 HTTP 加载，请使用此预览地址，避免直接双击 HTML 产生浏览器文件访问限制。

无依赖安装、构建、登录或后台。静态资源均使用相对路径，继续兼容原 GitHub Pages 子路径。

## 当前玩法

四轨下落。大鼓、小锣、铜钹、木鱼碰线时点击实际方块；唢呐按住按进度计 10、20、30 分，提前松开不扣血；完全未开始按住的长条仍算漏拍。累计三次失误立即结束，同一个方块只结算一次。完整演奏约 3 分 4 秒的原录音后正常结算。

普通方块基础 10 分，每 10 连击增加倍率，最高 3 倍；完美判定另加 10 分。唢呐不足 1/3 计 10 分、达到 1/3 但不足 2/3 计 20 分、达到 2/3 计 30 分，不受连击倍率影响；准确起音且按到最高档额外获得完美奖励。失误清空连击。六阶段保留主题、图形和速度变化；原录音保持原速，方块顺序固定，方块为浅金色纸面。当前 445 个音符中有 12 个唢呐长按、27 组双乐器同拍；长按期间无其他待点音符。触屏可用双指，鼠标可在判定窗口依次点击两个方块。

暂停后两秒倒计时接回原曲的同一位置。暂停中的长按只重置剩余部分，可在恢复倒计时期间提前按住；不移动之后的音符，不改变录音拍点。音频设备中断、切换后台或窗口失焦时暂停。

## 音频与还原范围

按用户最新选择，以完整原录音跟奏为优先：保留旋律、原速和速度变化。四种打击乐命中播放提供的小样，去掉播放前留白；唢呐长按增强同一原录音的中高频旋律，不把另一段短旋律叠在原曲上。单独唢呐文件提供短促结算音，合奏录音不可用时也作为长按降级音源。

谱面按录音中的瞬态起点选取可玩的落点，再编排打击乐角色。它是四轨游戏改编，不能视为逐件乐器的分轨转录。照片乐谱记有 C 调、4/4 引子和 2/4 主体；是否与该录音属于同一版本尚未确认，本版没有据照片强制改变原录音。

页面不再使用合成乐器与合成背景。进入网址先加载并解码必要声音和画面，完成后才进入封面。资源失败时停留在有明确提示的加载页，可点击重试；不会带着缺失背景音乐进入游戏。手机声音权限在点击时解锁。
